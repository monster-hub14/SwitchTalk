SwitchTalk 1.1.0 source build
Use devkitA64 r28/GCC 15.1.0, libnx 4.12.0, and Switch portlibs curl, zlib,
opus, minizip and mbedTLS. The existing RTC archive and source are under app/vendor/rtc.
The libultrahand revision bundled with Ultrahand 2.5.3 is vendored unchanged.

Windows Python + PowerShell:
 python tools/build-release.py <SDK> <TinyCC-directory>
 python validate_app.py
 python validate-launcher.py
 python overlay-worker/verify.py <SDK> <TinyCC-directory>
 python tools/verify-release.py <SDK> <TinyCC-directory> <native-clang++>
 python tools/prepare-release.py <output-directory>

The build first produces matching worker/overlay/controller files, embeds them and
hashes plus a public CA bundle in RomFS, then builds the app and stable launcher.
The native Windows build_romfs helper and its C sources are under app/tools.
No GitHub credentials belong in clients, source, RomFS or release archives.
App C++ uses GNU++26 for the installed SDK headers; native tests use C++17.
TinyCC is for host C tests/npdmtool, never the Switch compiler. The Makefile only
builds the app payload and expects generated companions first. Use the script above
for a complete installer. Old golden packaging tools are historical.

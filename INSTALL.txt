SwitchTalk 1.1.0 - Monster Review

ONE-TIME UPDATER INSTALL: close SwitchTalk, copy the COMPLETE switch and atmosphere
folders to your SD root, merge/replace, and reboot. Keep account/settings files.
Launch SwitchTalk from hbmenu as usual. SwitchTalk.nro is now the stable launcher;
app-a.nro is the initial application. Do not replace the launcher with the separate
SwitchTalkApp.nro update asset. Keep /switch/SwitchTalk/ in place.

An existing Nextcloud server with Nextcloud Talk installed/configured and an account
is required. SwitchTalk is a client, not a self-contained communication service.

AUTOMATIC UPDATES ARE ON BY DEFAULT AND OPTIONAL
In sign-in or Conversations, press ZL (or tap ZL Updates), then X until it says
AUTOMATIC UPDATES: OFF. B returns. This choice stays saved after restarts.
Disabling requests transfer cancellation and prevents automatic installation.
Chat/calls/notifications still work. A checks/downloads manually while off; A again
installs once verified. X enables automatic checking for the next app launch.
B/Later only postpones this session. Y restores an older verified slot and turns
automatic updates off. A backup becomes available after a subsequent update.

Enabled checks start when opening the FULL app. HTTPS downloads must pass size,
hash, identity and version checks. Installation waits outside chats/calls and
active operations for a five-second restart countdown; B postpones. The matching
overlay/worker/controller synchronize on startup. A running worker is stopped
before replacement and restarted where possible. Return to Ultrahand's main menu
before reopening the updated overlay. The worker/overlay do not check by themselves.

The executing slot is never overwritten. Reopen through hbmenu if automatic restart
is unavailable. If a selected slot or companion install fails, reopen to recover
from the previous verified slot/bundle. Reinstall the full ZIP if no slot is valid.
The launcher's hbmenu icon/version stays fixed; the running app shows its own version.
Saved sign-in and update preferences are never included or overwritten by this ZIP.

Existing overlay controls and foreground calls are unchanged. See README.md and
UPDATES.md. This exact updater/relaunch still needs a physical Switch test.

WHICH NRO SHOULD I OPEN?
Always open SwitchTalk.nro from Homebrew Menu. It is the stable launcher.
app-a.nro is the real application; keep it beside the launcher. A future update
creates app-b.nro as the alternate slot. The launcher selects the verified slot
for you and retains the other version for recovery. Keep all supplied .txt files.
Do not delete/rename these files, move them apart, or replace the launcher with
app-a.nro, app-b.nro or the separate SwitchTalkApp.nro updater asset.
